# 每日早报/晚报 (Daily Digest) - 需求规格

## 概述
基于用户兴趣标签，每天早8点/晚8点生成个性化"5分钟速览"，包含今日热点+感兴趣领域动态，建立用户"早晚看一眼"的使用习惯。

## 功能需求

### 1. 摘要卡片展示
- 在推荐页顶部展示"📋 实时热榜 Top 5"卡片（复用现有 `renderDailyDigest`）
- 数据来源：头条、百度、微博三大平台热搜
- 每条显示：排名序号、标题、平台徽章

### 2. 个性化推荐
- 基于用户选择的兴趣标签（TOPIC_KEYWORDS）筛选热搜
- 优先展示与用户兴趣匹配的热搜条目
- 无兴趣标签时展示全平台热度最高的5条

### 3. 交互
- 点击热搜条目直接跳转到原文
- 点击"更多"展开查看 Top 10
- 支持实时更新（随热搜数据刷新）

## 技术设计

### 数据流
```
hotItems → selectRecommendDigestItems(hotItems) → renderDailyDigest()
```

### 关键函数
- `selectRecommendDigestItems(hotItems)`: 筛选头条/百度/微博平台，按热度排序取Top5
- `renderDailyDigest()`: 渲染摘要卡片HTML

### 优化点
1. 增加兴趣标签过滤：优先展示用户关注领域的热搜
2. 增加"展开更多"功能：默认5条，展开显示10条
3. 增加时间标记：显示"早报/午报/晚报"根据当前时段

## 验收标准
- [ ] 推荐页顶部展示热榜Top5卡片
- [ ] 点击条目能跳转到原文
- [ ] 数据来自头条/百度/微博三大平台
- [ ] 支持展开查看更多
- [ ] 根据用户兴趣标签优先展示相关内容
