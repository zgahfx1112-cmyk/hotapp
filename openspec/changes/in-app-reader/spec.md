# 应用内阅读模式 (In-App Reader) - 需求规格

## 概述
点击文章不跳外链，在应用内渲染全文内容，支持调整字号/排版，提升单次阅读时长2-3倍，降低跳出率。

## 功能需求

### 1. 阅读视图
- 点击RSS文章卡片时，在应用内打开阅读视图（Modal/Drawer）
- 显示：标题、来源、发布时间、正文内容
- 支持关闭返回原页面

### 2. 内容获取
- 优先使用文章已有的 summary 字段
- 支持"加载全文"按钮，通过后端代理抓取原文页面并提取正文
- 失败时降级显示摘要+外链跳转按钮

### 3. 排版控制
- 字号调节：小/中/大三档
- 支持亮色/暗色主题跟随

### 4. 操作栏
- 收藏按钮
- 分享按钮（短链接）
- 原文跳转按钮（外链打开）

## 技术设计

### 后端 API
```
GET /api/reader?url={encoded_url}
Response: { title, content, error? }
```

### 正文提取逻辑（Python hotapp/reader.py）
1. 使用 urllib 抓取目标页面
2. 提取 `<article>` 或 `<main>` 或 `.post-content` 等常见正文容器
3. 清洗：移除 script/style/iframe/nav/footer
4. 保留 img/p/h1-h6/ul/ol/blockquote/a 等标签
5. 返回清洗后的 HTML

### 前端组件
- `openReader(url, article)`: 打开阅读视图
- `renderReaderModal(content)`: 渲染阅读Modal
- CSS: 阅读视图样式（字号、行高、段距、图片适配）
